{{ tr('1. Introduction') }}

The {{ tr('Smart Civic Complaint Management and Tracking System') }} operates as a digital public administration platform designed to facilitate transparent, accountable, and time-bound civic grievance redressal for citizens and municipal stakeholders.

{{ tr('We are committed to maintaining the confidentiality, integrity, and lawful processing of all personal information entrusted to us. This Privacy Policy details our practices concerning the collection, storage, utilization, transfer, and safeguarding of information provided by users when accessing our portal, lodging civic grievances, or communicating with municipal departments.') }}

{{ tr('This policy is formulated in accordance with applicable Indian laws, statutory rules, and administrative standards governing electronic communications and information security, including the Information Technology Act, 2000 and the Information Technology (Reasonable Security Practices and Procedures and Sensitive Personal Data or Information) Rules, 2011.') }}

{{ tr('2. Information We Collect') }}

{{ tr('To deliver responsive civic services and verify the authenticity of complaints, we collect information across three primary channels:') }}

  • {{ tr('Direct Citizen Submissions:') }} {{ tr('Data provided during account registration, grievance registration, or feedback submission.') }}
  • {{ tr('Civic Incident Details:') }} {{ tr('Grievance descriptions, affected municipal ward/zone, geographical coordinates, physical landmarks, and supporting media files.') }}
  • {{ tr('Automated System Telemetry:') }} {{ tr('Technical logs, session state, browser identifiers, IP addresses, and HTTP request headers necessary for server security and operational monitoring.') }}

{{ tr('3. Personal Information') }}

{{ tr('When registering as a citizen on this portal, we collect the following personal identifiers:') }}

  • {{ tr('Full Legal Name:') }} {{ tr('Used for authenticating grievance submissions and official correspondence.') }}
  • {{ tr('Mobile Number (10 Digits):') }} {{ tr('Essential for real-time SMS status alerts, automated verification, and tracking without password dependencies.') }}
  • {{ tr('Work or Personal Email Address:') }} Used for account verification, password resets, escalation notices, and formal dispatch summaries.
  • {{ tr('Residential Ward / Zone Location:') }} {{ tr('Necessary for automatically dispatching civic tickets to the competent municipal engineering division.') }}

Citizens are advised not to submit sensitive financial credentials, government identity cards, or unnecessary private details within complaint descriptions or photo attachments.

{{ tr('4. Account Information') }}

{{ tr('The platform maintains distinct role-based access privileges for four user categories:') }}

  • {{ tr('Citizen Accounts:') }} {{ tr('Managed via personal email/mobile credentials for complaint registration, tracking, and satisfaction feedback.') }}
  • {{ tr('Department Officers:') }} {{ tr('Official administrative credentials tied to designated municipal departments (e.g. Roads, Water Supply, Sanitation).') }}
  • {{ tr('Field Workers:') }} {{ tr('Assigned service credentials allowing field status updates, before-and-after photo uploads, and task completion logs.') }}
  • {{ tr('System Administrators:') }} {{ tr('Privileged credentials for audit log oversight, category configurations, user management, and escalation monitoring.') }}

{{ tr('All authentication secrets are protected through one-way cryptographic salted hashing (PBKDF2 with SHA-256) and are never stored in plaintext.') }}

{{ tr('5. How We Use Information') }}

{{ tr('We process collected data strictly for legitimate public administration and civic redressal purposes:') }}

  • {{ tr('Grievance Intake & Routing:') }} {{ tr('Assigning submitted complaints to appropriate zonal engineers and field repair crews.') }}
  • {{ tr('Service Level Agreement (SLA) Tracking:') }} {{ tr('Calculating resolution due dates and executing automated supervisory escalations for delayed repairs.') }}
  • {{ tr('Citizen Communication:') }} {{ tr('Transmitting ticket status notifications, inspection remarks, and closure confirmation notices.') }}
  • {{ tr('Evidence Verification:') }} {{ tr('Validating field work completion via comparison of pre-repair and post-repair photographic evidence.') }}
  • {{ tr('Municipal Quality Analytics:') }} {{ tr('Generating anonymous aggregate performance indices across municipal zones to enhance civic infrastructure.') }}

{{ tr('6. Data Storage and Security') }}

{{ tr('All citizen data, grievance records, and evidence media are hosted on secure database and application servers physically located within the territorial borders of India in adherence to national data localization principles.') }}

{{ tr('Our security architecture includes:') }}

  • {{ tr('Cryptographic Safeguards:') }} {{ tr('High-iteration PBKDF2 password hashing and TLS 1.3 encryption for all data in transit across public networks.') }}
  • {{ tr('Role-Based Access Control (RBAC):') }} {{ tr('Strict software permission gates preventing unauthorized cross-role data access.') }}
  • {{ tr('Injection Prevention:') }} {{ tr('Parameterized SQL queries and Object-Relational Mapping (ORM) to mitigate SQL injection vulnerabilities.') }}
  • {{ tr('Audit Logging:') }} {{ tr('Immutable timestamped audit trails of all administrative actions, grievance status changes, and technician dispatches.') }}

{{ tr('7. Information Sharing') }}

{{ tr('We do not sell, trade, rent, or disclose personal citizen data to commercial advertising networks or third-party marketing brokers.') }}

{{ tr('Data is shared solely under the following necessary circumstances:') }}

  • {{ tr('Assigned Municipal Departments:') }} {{ tr('Relevant complaint descriptions, location data, and citizen contact details are shared with designated municipal engineers for grievance resolution.') }}
  • {{ tr('Field Service Technicians:') }} {{ tr('Contact numbers and incident landmarks are accessible to assigned technicians solely for locating civic disruptions.') }}
  • {{ tr('Statutory & Legal Requirements:') }} {{ tr('Information may be disclosed where mandated by valid judicial orders, warrants, or legally binding summons issued by Indian law enforcement agencies.') }}

{{ tr('8. Data Retention') }}

{{ tr('Personal data and grievance records are retained in active storage for the duration necessary to resolve the submitted grievance and satisfy statutory municipal audit standards.') }}

{{ tr('Resolved complaints and photographic verification records are preserved in read-only public administration archives for a minimum period of 3 years to support warranty inspections, public audit evaluations, and historical infrastructure planning.') }}

{{ tr('9. User Rights') }}

{{ tr('As a citizen user of this portal, you hold the following privacy entitlements:') }}

  • {{ tr('Right to Access:') }} {{ tr('View all complaints, timeline updates, officer remarks, and uploaded proofs associated with your account.') }}
  • {{ tr('Right to Rectification:') }} {{ tr('Request correction of inaccurate contact numbers, profile names, or communication preferences.') }}
  • {{ tr('Right to Track Anonymously:') }} {{ tr('Track public complaint resolution progress using only the unique Complaint Reference ID without logging into an account.') }}
  • {{ tr('Right to Withdraw Consent:') }} {{ tr('Revoke optional cookie preferences and non-essential analytical tracking at any time.') }}

{{ tr('10. Access, Correction and Deletion Requests') }}

Citizens wishing to access their stored personal profile, request corrections, or request account deactivation may submit an electronic request through the official Civic Help Desk or contact our administrative team at civic-desk@gov.portal.

{{ tr('Requests are verified against the registered mobile number or email address before processing. While account profiles may be deactivated, historical civic complaint tickets submitted to municipal logs are retained as official municipal public records.') }}

11. Children's Privacy

{{ tr('This portal is an enterprise civic grievance management platform intended for general civic use. We do not knowingly solicit or collect identifiable information directly from individuals under 18 years of age without parental or guardian oversight.') }}

{{ tr('If a parent or guardian discovers that a minor has submitted personal information without consent, they may contact our support desk to review or remove such information.') }}

{{ tr('We may revise this Privacy Policy periodically to reflect technological updates, changes in administrative procedures, or updated statutory guidelines.') }}

All revisions will be published on this page with an updated "Effective Date" and version number. Continued utilization of the portal after such updates constitutes awareness of the revised provisions.
